# 本地三维观测界面

构建：`npm --prefix web ci && npm --prefix web run build`（Node 24）。
启动：`./scripts/start_lab.sh --profile navigation --continuous --web --headless`，浏览器打开 `http://127.0.0.1:8080`。

观测进程只订阅标准 ROS 数据；独立的 loopback WebSocket 为 `127.0.0.1:8765`。四个点云图层各保留最新帧，5Hz、每层最多10万点。配准累积层是有界显示窗口，不能代替建图结果；显示降采样和无效返回过滤分别标注，rosbag 仍保留完整接收数据。原始数据按源时间变换，最多允许150ms的相邻显示变换并在帧元数据中记录差值；全局优化地图使用当前 map→odom 修正并保留原始源时间，不向控制器提供数据。

左键旋转、右键平移、滚轮缩放；可切换高度/强度、跟随无人机和复位。后台断连时保留缓存点云并明确标记，解锁状态变为未知，配置选择禁用。慢浏览器150ms发送期限超时后断开，队列不积压。观测进程/HTTP进程退出会记录 web-failure.json，飞行监督继续运行；启动阶段端口冲突会在飞行前失败并清理本次进程。

当前后端下拉列表为下一实验草稿，尚不发送控制命令；完整实验启动、回放和报告在后续交付接入。真值订阅默认关闭，独立评估显示随后验收。
