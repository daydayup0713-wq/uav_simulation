## 实际传感器与飞行

本机 Ogre2 EGL 使用 NVIDIA Corporation / NVIDIA GeForce RTX 3050 Laptop GPU（OpenGL）。初次 EGL 设备探测的 dri2 警告不影响最终渲染；实际雷达与图像数据经过验证。该证据只证明本版本的传感器渲染，不证明 CUDA 算法能力。

离线 `bag-check` 通过；独立域77实际播放通过，播放器退出0、live audit通过，活动域42保持独立。best effort回放实收15890条IMU，最大间隔0.08s；这不是无损传输承诺。未来算法固定数据集基准应离线读取原bag，并按源间隔处理。

## 发布门禁与限制

V0.2.0 所有发布门禁通过。初次V0.2干净CI在32cb990提交通过固定依赖构建、回归、三轮飞行和失控降落；[首次 CI](https://github.com/daydayup0713-wq/uav_simulation/actions/runs/37197219842)。审查修复提交02bd804的[最终 CI](https://github.com/daydayup0713-wq/uav_simulation/actions/runs/37199496965)全部通过：六包构建、80项回归（11.01秒）、三轮飞行最大悬停误差0.10971 / 0.11075 / 0.11931m、断桥后7.55992秒确认 landed + disarmed，armed AUTO_LAND独立观察通过。

CI 实际测试 PR 合并提交49bc3fe，其父提交为V0.1基线b823eba和功能提交02bd804；源归档容器通过LAB_REVISION保存版本。CPU配置不渲染相机或GPU雷达，本机渲染证据分别验收。[CI机器可读证据](v02-clean-ci.json)包含运行链接、提交关系、飞行/故障结果和证据包SHA256。之后的发布归档提交只补充文档和JSON证据，功能代码未改变。V0.1旧版CI证据没有用作本版验收。

模型为学习用途；0.05kg载荷、通用同步扫描、白噪声IMU、无畸变相机，尚无Mid-360逐点时间、真实时延、SLAM、无GNSS飞行或自动避障。生成参数源与数据契约见 [V0.2设计](../superpowers/specs/2026-10-04-v02-sensors-design.md)。
