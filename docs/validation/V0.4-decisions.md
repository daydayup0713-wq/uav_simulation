# V0.4 执行取舍

完整执行记录将在阶段验收后归档。以下为已采用的主要选择：

- 批准的路线和继续V0.4请求授权实施；在固定项目检出中从v0.3.1建立feature分支，保留原版本标签。成本是无额外物理工作树隔离。
- 有界稠密三态网格和3D A*便于学习、固定输入复现和未知空间保守判断；无OctoMap/ESDF额外原生依赖。成本是范围及分辨率固定、保守间隙。
- 实际传感器射线以最多四分之一体素步长向量采样；碰撞用精确supercover。漏掉很小的射线体素交集仍是未知，不会创建自由通道。
- 加入人工HOLD/LAND世代字段，导航航段在适配器接收和执行时均检查；旧profile忽略该字段。成本是Action内部契约增加字段，需要重建工作区。
- 机体垂直半尺寸由.15改.30m，来源为固定x500脚架/载荷几何，成本是更保守的垂直空间。
- 导航雷达扩展垂直视场并降低水平束数，来源为实际盲区和数据频率测量；它是通用学习雷达，成本是不能声称Mid-360扫描逼真度。
- 同一CPU上并行仿真/定位/导航，地图归档移到单独有界工作线程，限制BLAS线程；不会放宽失效门槛来获得演示通过。
