# V0.4 执行取舍

本版在批准的路线内执行。以下记录选择、证据及代价；完整本机执行档案保留在`.superpowers/archive/2026-10-07-v04-navigation`。

- 批准的路线和继续V0.4请求授权实施；在固定项目检出中从v0.3.1建立feature分支，保留原版本标签。成本是无额外物理工作树隔离。
- 有界稠密三态网格和3D A*便于学习、固定输入复现和未知空间保守判断；无OctoMap/ESDF额外原生依赖。成本是范围及分辨率固定、保守间隙。
- 实际传感器射线最终以最多二分之一体素步长向量采样，碰撞用精确supercover。原四分之一步长在原生并发环境下占用较多映射时间，cProfile测得积分.209秒/回调.244秒后作此调整。代价是可能遗漏很小的射线体素交集，保留为阻挡未知，不能凭插值创建自由通道。
- 加入人工HOLD/LAND世代字段，导航航段在适配器接收和执行时均检查；旧profile忽略该字段。成本是Action内部契约增加字段，需要重建工作区。
- 机体垂直半尺寸由.15改.30m，来源为固定x500脚架/载荷几何，成本是更保守的垂直空间。
- 导航雷达扩展垂直视场并降低水平束数，来源为实际盲区和数据频率测量；它是通用学习雷达，成本是不能声称Mid-360扫描逼真度。
- 同一CPU上并行仿真/定位/导航，地图归档移到单独有界工作线程，限制BLAS线程；不会放宽失效门槛来获得演示通过。
- Task1/2固定观测生产与规划消费测试交错实施，Task3飞行高度下可观测性与Task4控制门禁一起原生验证。接口仍按依赖顺序设计、RED→GREEN、分步提交，代价是工作区存在跨任务集成变更，由一次全分支审查覆盖。
- 有界8扫描队列保留可由LIO位姿插值的扫描，禁止外推。新扫描曾抢先覆盖已有位姿覆盖的样本导致过期锁定；短队列以延迟/内存换取连续源时间处理，不改变数据新鲜度门槛。
- A*在独立spawn CPU进程执行，传入不可变108000格快照；仅分回调组无法隔离Python GIL。代价为额外进程和快照传输。搜索2秒/50000展开，与不可达原因分开；worker退出、超时均锁定并报告明确失败。
- 计划地图按随机节点会话和版本排他创建，在同一锁内完成写入及哈希，避免恢复后版本重用和并发空文件哈希；代价为每计划保留小型压缩地图。周期快照仍用于学习，但不替代原计划碰撞证据。
- 节点及CLI持续拥有未确认的Action请求，迟到接受主动取消；无法确定停止结果时失效锁定。代价为有界清理等待、需重启实验恢复，不自动续飞。
- 同步独立评估器与三轮演示由验收脚本编排，超时/中断请求有界LAND。真值与场景几何始终独立，代价为评估进程和日志；不以规划器自报无碰撞替代实际净距测量。
- 参考速度/加速度.5/.5与实际峰值速度.7304m/s分别报告；V0.4不宣称动力学或jerk标定。起降仍由已有飞控适配执行，当前路径避障只覆盖空中导航段。
- 一次独立最终审查的6项Important全部在一次修复批次内复现及修复，并完成187项回归、第二套原生三轮及即时恢复锁定。原过晚恢复探测未获得服务，被记为失败，不用它支持恢复行为结论。
- 录制/地图/ULog大文件留在忽略目录，Git保存小型JSON数值、输入哈希及本机路径。传感器210秒录制来自审查前同配置运行，最终飞行和地图来自ff2eddb；代价是重放大文件需本机档案或自行重新采集，不能把所有证据误标为同一源码运行。
