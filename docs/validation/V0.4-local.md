# V0.4 本机验收

三维导航采用连续odom、源时间插值LIO、冻结控制适配、.2m三态占据网格和有界26邻域A*。未知区域阻止机体体积通过。初始离线基准和真实ROS契约通过；最终原生飞行/CI结果在本阶段完成后补入。

开发测量发现90°垂直雷达使起点上方体积未观测，规划器正确拒绝；导航专用通用雷达调整为约179°垂直视场。64×360带来偶发10Hz契约失败，最终采用64×180，保持11520束/扫描。旧版本雷达不变。机体半包络修正为(.4,.4,.3)m，包括标准x500脚架及载荷；加.25m裕度并向体素外取整。

实时映射保留8扫描短队列，避免新点云覆盖已有位姿覆盖的扫描；严格不外推位姿。自身回波只按配置机体包络过滤。归档独立线程，单机OpenBLAS1/OpenMP2；实际16358端点的同一地图输入，积分从.1099s降为.0678s，空闲61564格一致。曾发生过期锁定和启动传感器频率失败，未放宽安全阈值，失败运行保留在.runtime。

固定解析观测只验证契约与安装，不替代渲染飞行或实机精度。V0.4仅验收静态、已观测空间，不提供自主探索或动态物体预测。实际速度和参考速度分开统计；不声称机型动力学或jerk标定。
