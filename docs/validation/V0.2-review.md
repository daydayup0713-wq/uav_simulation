# V0.2 最终审查与回归

2026-10-04，独立审查覆盖 `b823eba..33f9835` 全部分支。没有 Critical 或 Minor；五项 Important 在同一修复阶段处理，没有遗留项。

| 发现 | 修复和失败复现测试 |
|---|---|
| SIGTERM 留下 recorder/player 子进程 | 限定作用域的 SIGINT/SIGTERM 处理进入 finally；真实 ROS `test_interrupted_record_closes_owned_rosbag` 验证两种信号、元数据落盘与进程退出 |
| /clock 与全部传感器一起暂停仍可能通过 | 实时检查增加单调时钟进度和接收期限；`test_paused_live_clock_fails_but_offline_read_speed_does_not` |
| 长时间断流被平均频率掩盖 | 校验最大源时间间隔；`test_long_sensor_outage_cannot_hide_in_average_frequency` |
| 低实时率录制按源时长计算播放超时 | 改用 bag 接收时间轴；`test_slow_simulation_replay_uses_receive_timeline` |
| ros2 包装进程先退出后不清理后代 | 始终按本次新建的进程组清理；`test_owned_cleanup_stops_child_after_wrapper_already_exited`，使用真实退出包装进程和忽略 SIGINT 的子进程 |

新增用例在修复前复现五项失败；修复后专项测试25项通过，全量80项通过（11.57秒）。源时间倒退仍拒绝；离线审计与实时停滞判定分别处理。

审查提出的空间证据补充：从已录制原始点云抽取40帧，采用独立 Gazebo 真值及 FLU 安装外参转换到 sim_world，与已知地面 z=0 和室内墙 x=±9.9/y=±7.9 比较。13帧存在机体倾斜；19721个中央地面点的95%误差小于0.01941m，148751个墙点小于0.03420m。真值匹配时间差最大0.04s。该检查验证本模型的坐标和外参链，不能替代实机标定；结果见 [几何验证](v02-geometry.json)。

执行决定（审查未判断部分）：

- 实机物理/传感器逼真度保持学习模型边界，按未来实测校准；若被当作一比一模型，会错误估计实机性能。
- Mid-360逐点时间、SLAM、无GNSS飞行与避障按已批准路线后续交付；若用户将本版任意航点当作已避障，会发生仿真碰撞。
- 本版 CPU 回归与干净 CI 必须获得实际结果；旧版 CI 和本机传感器通过不代替干净安装验证。

没有推迟的 Minor。发布门禁状态见 [本机与发布验证](V0.2-local.md)。
