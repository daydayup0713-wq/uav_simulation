# L1 多算法实验台：已批准设计

本设计固化用户于 2026-10-08 批准的 L1 升级计划。基线为 `v0.4.0`（e295a54），实施分支为 `feat/l1-workbench`。真机本轮仅提供配置和接入准备，飞行验收在 PX4 SITL 中进行。

## 目标与边界

保留 Gazebo、RViz、CLI、GLIM 和 V0.4 A* 回归，新增独立 React/TypeScript/Three.js Web 实验台。同步建设室内无 GNSS、室外 RTK 对照。算法成绩以相同传感器输入组比较，不预设“最好”。定位和规划各只运行一个后端，批量实验顺序执行。

定位后端：GLIM、FAST-LIO2、FAST-LIVO2、FAST-LIVO2-RTK、ORB-SLAM3、LIO-SAM、VINS-Fusion。规划后端：A* 加连续轨迹、官方 EGO-Swarm ROS2 分支单机、FAST-Planner、安全走廊加 GCOPTER/MINCO。ROS2 接口移植保留上游计算逻辑；依赖独立、固定提交、注明来源和许可证。分别记录安装、回放、实时、闭环资格，未运行的阶段不得标绿。

连续局部里程计、全局地图修正、健康状态、时间参数轨迹采用统一适配契约。地面选择后端，飞行中拒绝切换。里程计、回环、重定位、全局优化分开标注。RTK 后处理不跳变飞控目标。飞控适配器仍是唯一 `/fmu/in/*` 发布者；算法输入不包含仿真真值。

## 飞行与数据

轨迹传递位置、速度、加速度、航向、航向变化率；至少 C2 连续。参考限速 0.5m/s、加速度 0.5m/s²、jerk 1m/s³；50Hz 轨迹执行、20Hz Offboard 心跳。中间点连续通过，末端及明确停留点稳定。重规划衔接当前轨迹状态；曲线全程做机体包络和未知空间检查，停止遵守动力学约束。HOLD/LAND 可打断，定位或通信失败沿用已验收失控降落，不自动续飞。

保留旧传感器，新增 Livox 类雷达/IMU/单目、上述加 GNSS/RTK、旋转雷达/姿态 IMU 三组。扫描必须随测量时刻运动生成，不能给同步点云伪造逐点时间。相机默认 640×480@30Hz，IMU 200Hz；时间、外参、噪声、同步误差进入记录。LIO-SAM 的 ring/time/姿态初始化须满足实际契约，姿态不能直接用完美真值替代。

六类固定实验：圆形和八字、多高度螺旋、多房间闭环、重复结构长走廊、密集静态障碍、室外长路线加 RTK 中断。每条 20–50 个语义控制点，轨迹采样独立。先固定路线定位、固定传感器地图规划，再候选组合闭环；预先建图和在线局部更新分开，本轮不做自主探索。

## Web 与验收

深色大幅 3D 视图、紧凑状态面板；原始单帧点云、配准累积、全局优化地图、障碍体素独立图层。显示计划/实际轨迹、机体、跟随/复位视角、高度/强度着色；场景/后端选择、运行状态、回放、指标和比较报告。真值只在评估模式显示。

观测桥独立于控制链，默认 5Hz、最多 100000 点/帧、最新帧有界队列，显示降采样明确标记，录制保留完整数据；慢浏览器和断连不阻塞算法和飞控。实验生命周期仍由监督器所有。

验收：原 187 项回归和飞行门禁；定位 ATE/RPE/姿态/覆盖率/延迟/CPU/RSS；规划成功率/耗时/长度/净距/速度/加速度/jerk/实际跟踪。正常闭环 P95 跟踪误差目标 ≤0.3m、三次重复；独立碰撞评估；连续转弯、重规划衔接、HOLD/LAND、定位退出、数据过期、RTK 异常、Web 断连。失败保留报告，不自动允许控制。默认组合由正常验收实测选择后验证退化。
