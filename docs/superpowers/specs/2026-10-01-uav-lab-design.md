# UAV Simulation Lab 设计基线

独立建设学习、算法验证和巡检数字孪生平台。旧学习包和 Edge/Cloud 仅供参考，不是运行依赖。

## 系统分层

仿真生成传感器与独立真值；自主系统生成定位、地图与轨迹；任务系统调度导航与采集；控制系统管理遥测、控制权和飞行；AI 系统生成带证据的检测；数字孪生管理几何、实景、业务图层。

ROS 使用 ENU/FLU，PX4 NED/FRD 转换只在飞控边界。只有适配节点发布 /fmu/in。真值只给评估器。记录运行 ID、版本、参数、标定和坐标变换。

## V0.1 范围

Ubuntu 22.04 / Humble / Harmonic，单 x500，空旷世界，CLI + Gazebo/RViz。系统 Python 3.10。依赖固定在 dependencies/lock.json，Agent 2.4.3 私有安装。独立 ROS 工作区，不加载旧 overlay。

服务 /uav001/arm、disarm、hold 使用 Trigger；动作 execute_flight 使用 TAKEOFF/GOTO/LAND。反馈阶段和位姿；结果成功状态与原因。起飞必须显式解锁，空中普通 disarm 拒绝。取消运动悬停，降落不可取消；land/hold 可打断运动。

20 Hz 心跳、2 秒预热、ACK 与实际状态双确认。姿态/位置/飞控状态必须新鲜；失联不自动续飞。控制时间和消息时间分离。

演示：显式解锁、2m 起飞、10s 悬停、3m 方形四航点、回原点、降落。速度 <=1m/s；误差 <=0.3m 持续2s。三次连续演示通过，降落由 landed + disarmed 确认。异常、依赖缺失和实例冲突及时退出，保留证据。
