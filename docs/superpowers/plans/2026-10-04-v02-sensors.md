# V0.2.0 Sensors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在本机完成可观测、可录制、可回放的通用传感器实验室。

**Architecture:** 单一 JSON 数据契约生成 SDF、桥接和静态 TF。传感器节点只归一化 IMU 观测；数据工具负责验收和 rosbag 生命周期，保留原飞控边界。

**Tech Stack:** Ubuntu22.04 / Humble / Harmonic8，Python3.10/rclpy，ros_gz_bridge，rosbag2 sqlite3。

**Spec:** docs/superpowers/specs/2026-10-04-v02-sensors-design.md

## Global Constraints

- 命名空间 /uav001；ENU/FLU，飞控适配仍唯一 fmu 输入发布者。
- 保留源时间 /clock，单调时钟超时；独立真值不接控制 TF。
- 低分辨率传感器；保留 flight CPU CI；不修改固定依赖源码。
- 既有 V0.1 两项交互修复已保存到新分支；沿用用户指定本机独立仓库路径与现有私有依赖，避免重复下载、构建。

## Review Focus

- 回放域与活动飞控隔离，以及包中混入 /fmu/in 的拒绝。
- 相机光学系旋转与真实 Gazebo 点云坐标一致。
- 源时间倒退、暂停和消息丢失的验收结果。
- 录制被中断时 rosbag 关闭、元数据与归档状态。
- 渲染失败不静默就绪，退出只清理本次进程。
